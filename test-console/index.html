Short checks that show how the engine behaves behind the screens.

It's a private service

Every request needs the service token. Without it the engine refuses.

Out-of-date answers are rejected

An answer must point at the exact question that was saved. A wrong reference is refused, so nothing is recorded twice or on the wrong question.

Nothing is lost on restart

Restart the engine and reopen the lesson: the same messages come back from the database.

Everything can be exported

The whole profile downloads as a ZIP in the original app's file format. A lesson also exports as Markdown.
